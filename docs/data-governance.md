# Data governance procedure

Use public professional data only for defined B2B purposes. Store source URL, collection time, verification state and lawful basis. Do not infer sensitive traits or use them in qualification.

For an access, correction or deletion request, verify the requester, search contacts, companies, activities and messages, export relevant records, correct inaccurate data and delete data where there is no overriding retention obligation. Preserve the minimum suppression hash needed to honour an opt-out. Record the decision and completion time.

Review records monthly. Delete stale evidence and contacts according to `DATA_RETENTION_DAYS`; pause deletion under a legal hold. Opt-outs apply immediately across sequences and sending and should not expire merely because other prospect data is removed.
